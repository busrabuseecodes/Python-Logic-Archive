# 🚀 Python Logic Archive

Bu depo (repository), Python programlama dilini temelden başlayarak adım adım keşfettiğim, mantık yürüttüğüm ve kendi çözümlerimi ürettiğim kişisel öğrenme yolculuğumu içermektedir.

Herhangi bir müfredata bağlı kalmadan, tamamen kendi emeğimle oluşturduğum bu arşiv; teorik bilgilerden karmaşık veri yapılarına kadar geniş bir yelpazeyi kapsamaktadır.

## 📂 Arşiv İçeriği

- **🏗️ 01. Teori ve Temeller (01_Theory_and_Fundamentals)**

Bilgisayar biliminin mutfağına giriş yaptığım bölüm. Donanım, yazılım ve programlama dillerinin çalışma mantığı (Compiler vs. Interpreter) üzerine notlar.

- **🔤 02. Değişkenler ve Metin İşleme (02_Python_Basics_and_Strings)**
Veri tiplerini tanıma, değişken tanımlama kuralları ve string (metin) operasyonları üzerine pratikler.

- **📐 03. Matematiksel Algoritmalar (03_Mathematical_Algorithms)**
Python'u bir problem çözme aracı olarak kullandığım; geometrik hesaplamalar (küre hacmi, yamuk alanı vb.) ve matematik kütüphaneleriyle yaptığım çalışmalar.

- **🚦 04. Karar Mekanizmaları (04_Decision_Making_and_Logic)**
Kodun "düşünmesini" sağlayan bölümdür.

**HTTP Status Code Checker:** Durum kodlarına göre tepki veren sistemler.

**Weather Advisor:** Hava durumuna göre mantıksal tavsiyeler üreten simülasyonlar.

- **🔄 05. Veri Yapıları ve Döngüler (05_Data_Structures_and_Loops)**
Verileri organize etmeyi ve yönetmeyi öğrendiğim en güncel aşama.

**Dictionaries & Sets:** Karmaşık veri gruplama (İç içe sözlük yapıları).

**Loops:** for ve while döngüleri ile veri setleri üzerinde otomatik işlemler.

## 🛠️ Kullandığım Teknolojiler
* **Dil:** Python 3.x

* **Araçlar:* Jupyter Notebook (.ipynb), Google Colab, VS Code
